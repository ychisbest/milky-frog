## 1. 版本更新提示

`wx.getUpdateManager`：新版本在后台下载完成后，**等玩家回到主菜单再弹窗**（不打断战斗），「立即重启」前先保存并上传云存档。每次启动最多提示一次。
发版后老玩家不会一直停在旧缓存版本，活动内容能及时推到。

## 2. 带参数分享 / 好友挑战

- 结算页「分享战绩」与右上角菜单转发的卡片都带 `query`：`ch=1&t=存活秒数&k=击败数&w=是否通关&d=每日挑战日期`
- 每日挑战结算分享的标题改为「今天的每日挑战我坚持了 X，同一关卡，敢来比比吗？」
- 好友点开卡片（冷启动或热启动）→ 主菜单弹出「好友的挑战」面板 → 「接受挑战」：
  - 卡片是**今天的每日挑战** → 直接进入同一个每日挑战（每日挑战按日期生成，全服相同）
  - 普通战绩 / 过期的每日挑战 → 开普通局
  - 新玩家（0 局）→ 先进入带新手引导的普通局
- 局内横幅显示目标时间，结算显示「你超过了好友的 X！」或「离好友的 X 还差 Y」
- **不发放任何奖励**，符合平台诱导分享规则

## 3. 游戏圈按钮

主菜单左上角（适龄标识下方）显示微信原生游戏圈按钮，离开主菜单即隐藏。`SOCIAL_CONFIG.gameClub = false` 可关闭。
后台（可选）：微信公众平台 → 「游戏圈」开通并设置版块，用于发布攻略、更新公告、收集反馈。

## 4. 添加到我的小程序

首次通关后回到主菜单，右上角胶囊下方出现一次提示「点右上角「···」选择「添加到我的小程序」」，点击关闭后不再出现（`Save.addTipShown`）。
微信没有直接添加的接口，只能引导；从「我的小程序」打开的场景值为 1089，可在埋点中看效果。

## 5. 好友排行榜

**主域**：每局结算调用 `wx.setUserCloudStorage` 上报两个键：
- `best`：最长存活秒数（`{ wxgame: { score, update_time }, kills, wins }`）
- `daily`：今日每日挑战最佳（带 `date`，开放数据域只显示当天）

**入口**：主菜单「排行」、每日挑战界面「好友排行」（默认打开今日挑战榜）。两个标签切换。

**开放数据域**：`build-templates/wechatgame/openDataContext/index.js`（纯 Canvas 绘制，前 100 名，头像、昵称、成绩，自己那行高亮，可拖动滚动）。

### 配置步骤（每次构建后）

1. Cocos Creator「构建发布」→ 微信小游戏 → 构建
2. 运行 `node tools/wechat-postbuild.mjs`：把开放数据域复制进 `build/wechatgame/openDataContext`，并在 `game.json` 中登记 `"openDataContext": "openDataContext"`
3. 微信开发者工具打开，菜单「排行」应能看到自己的成绩（开发者工具里只能看到自己，好友数据需真机）
4. 微信公众平台 →「设置 → 用户隐私保护指引」：好友关系链数据由开放数据域读取，主域拿不到；按平台要求如实填写「好友关系」用途：用于展示好友排行榜

> 如果 Cocos 项目设置里裁剪了引擎模块，确认「SubContextView / 开放数据域」相关模块没有被关闭，否则排行区域会是空白。

## 6. 云存档（微信云开发，默认关闭）

`SOCIAL_CONFIG.cloudEnv` 为空时完全不启用，游戏只存本地。启用后：
- 玩家**同意隐私政策后**才连接云端
- 启动时拉取云端存档：**局数多的一份优先**（局数只增不减），局数相同取更新时间晚的。所以新设备的空存档不会覆盖云端进度
- 云端更新 → 覆盖本地并提示「已从云端恢复游戏进度」；音乐 / 音效 / 震动 / 性能模式 / 隐私同意保留本机设置
- 拉取失败（离线）→ 本次不上传，避免用未知状态覆盖云端
- 存档变更后 3 秒内合并上传一次，切后台、重启更新前立即上传
- 隐私弹窗文案会自动加上「备份到微信云开发」

### 配置步骤

1. 微信开发者工具 → 顶部「云开发」→ 开通（基础套餐按月计费，个人主体可开通）
2. 云开发控制台 → 设置 → 复制**环境 ID**，填入 `SocialConfig.ts` 的 `cloudEnv`
3. 数据库 → 新建集合 `saves`，权限设置选 **「仅创建者可读写」**（每个玩家只能读写自己的存档，不需要云函数）
4. 同步修改 `marketing/文案/09_用户协议与隐私政策.md` 与后台「用户隐私保护指引」：说明游戏进度会备份到微信云开发
5. 真机测试：A 手机玩一局 → 删除小游戏重装（或换 B 手机同一微信）→ 应提示「已从云端恢复游戏进度」

## 7. 新手渐进解锁

主菜单入口按局数逐步开放，首局只有「开始游戏 / 选择角色 / 设置」，降低新玩家的信息量；之后每次开放都会提示「新功能开放：…」，相当于持续给新内容。

| 功能 | 开放条件 |
| --- | --- |
| 永久强化、成就、图鉴、签到、好友排行 | 完成 1 局 |
| 每日挑战 | 完成 2 局 |

- 未开放的按钮显示锁，点击提示「再玩 N 局即可开放」；红点在开放前不显示
- 只影响主菜单入口，不改变局内数值，数值模拟与回归测试结果不变
- 老玩家升级后不会重复弹出开放提示；好友挑战卡片仍可直接进入每日挑战（0 局的新玩家除外）
- 调整：`GameRoot.ts` 顶部的 `UNLOCKS`
