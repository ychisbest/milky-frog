# 奶蛙割草 · 数值设计

目标：让玩家处在"刚刚好"的紧张区间——每局都差一点、每局都有进步、每天都想再来一局。
所有结论都由 `tools/balance-sim` 的自动化模拟验证（见文末）。

---

## 1. 设计目标（可量化）

| 维度 | 目标 | 实测（30 名模拟玩家 × 6 局） |
| --- | --- | --- |
| 首局胜率 | 25–35%（大部分人差一点） | **≈31%**（普通 20% / 新手 43%） |
| 第 3 局胜率 | ≈50% | **≈50%** |
| 第 5–6 局胜率 | 60–70% | **≈55–60%** |
| 首胜所需局数（中位） | 2–3 局 | **2–3 局** |
| 被击败时间分布 | 峰值在 6–12 分钟（"差一点就到下个 Boss"） | 峰值 6–9 分钟，9–15 分钟占 1/3 |
| 升级节奏 | 0–2 分 8–12 s/级；2–6 分 15–20 s；6–15 分 20–30 s | 8–12 / 10–20 / 13–18 s |
| 首次进化 | 7–10 分钟 | 7.3–10 分钟 |
| 胜利局结束等级 | 60–70（构筑接近完成但不完美） | 60–70 |
| 全部养成完成 | 50–90 局（长线目标） | 约 55–90 局 |

> 难度曲线原则：**前期宽容（学习）→ 中期紧张（筛选）→ 终局高潮（红月 + 暗夜魔术师）**。
> 调参前实测发现曲线是反的（2 分钟史莱姆王最致命、后期几乎无威胁），已修正。

## 2. 成长曲线

### 2.1 升级经验（`Defs.ts · xpForLevel`）

| 等级段 | 每级所需经验 | 设计意图 |
| --- | --- | --- |
| 1–9 | 5 + 5×(lv−1) | 开局 8–12 秒一级，快速成型、立刻爽 |
| 10–29 | 60 + 14×(lv−10) | 中期 15–20 秒一级，每次选择更有分量 |
| 30–49 | 340 + 26×(lv−30) | 后期放缓 |
| 50+ | 860 + 45×(lv−50) | 胜利局约 60–70 级：6 武器满级 + 6 被动满级需 ≈78 次选择，故意差一点 |

### 2.2 升级选项权重（`Battle.ts · buildOptions`）

| 选项 | 权重 |
| --- | --- |
| 已有武器升级 | 3 |
| 已有被动升级 | 2 |
| 凑进化所需的被动（对应武器 ≥5 级） | 5 |
| 新武器（已有 <3 把） | 2.5 |
| 新武器（其余） / 新被动 | 1 |

效果：构筑更容易做深、凑出进化，减少"三个选项都没用"的挫败；随便选的玩家也不会被惩罚（模拟中随机选与精选胜率接近，但精选首次进化早 2–3 分钟）。

## 3. 敌人强度

### 3.1 小怪生命

```
HP = 基础HP × (1 + t/240 + (t/280)²) × 红月(1.3) × 心流系数
```

| 时间 | 0:00 | 5:00 | 10:00 | 15:00 |
| --- | --- | --- | --- | --- |
| 倍率（心流=1） | ×1 | ×3.4 | ×8.1 | ×15.1 |

### 3.2 小怪接触伤害（`dmgRamp`）

```
伤害 = 基础伤害 × (1 + 0.6m + 1.15m²) × 红月(1.25) × (0.8 + 0.2×心流)，m = t/600
```

前期平缓、后期陡峭：5 分钟 ×1.6，10 分钟 ×2.75，15 分钟 ×4.5。Boss 接触伤害不随时间成长。

远程小火灵（9:00 起）：保持约 230 距离游走，每 2.6~3.4 秒投掷火球（伤害 4×成长倍率），同屏上限 4 只起、每 2 分钟 +1；稻草人（11:00 起）：慢速高生命、抗击退。加入后整体伤害曲线下调一档，首局胜率维持在约 22%。

### 3.3 刷怪节奏要点

- 0–1:30 大量 3 血老鼠和蝙蝠（一击必杀），新手开局就能攒经验；1:15 第一波蝙蝠群是经验盛宴
- 云朵精（快速、抗击退）推迟到 **7:00** 才出现——实测它是 5 分钟"倒下墙"的元凶
- Boss 战期间小怪 −40%，让玩家专心对付 Boss
- **红月（13:00–15:00）**：地面变红、Boss 音乐、刷怪 ×1.8、精英 ×3、生命 ×1.3、伤害 ×1.25，敌人上限 340→420。最后两分钟是高潮，强构筑也要接受考验

### 3.4 Boss 生命

```
Boss HP = 基础HP × (1 + 0.1 × 玩家等级)
```

随玩家等级成长（同吸血鬼幸存者），保证强弱构筑都能打 30–100 秒。前两个 Boss（史莱姆王、铁甲将军）接触伤害降到 5 / 8——实测前期倒下主要来自它们。

### 3.5 心流系统（动态难度，玩家不可见）

| 状态 | 心流变化 | 效果 |
| --- | --- | --- |
| 生命 <35% | −0.03/秒 | 刷怪、生命、伤害放缓，给喘息机会 |
| 生命 >80% 且 6 秒未受伤 | +0.012/秒 | 碾压中，逐渐加压 |
| 生命 >50% | +0.003/秒 | 缓慢加压 |

范围 0.8–1.7。作用于刷怪数量（×心流）、怪物生命（≤1 线性，>1 时 心流^1.5）、接触伤害（0.8+0.2×心流）。
目的：高手不会无聊、新手不会被碾死，所有人都待在紧张区间。

## 4. 武器平衡

基准：同样 40 秒、满屏小怪时的伤害量。1 级时各武器控制在 **2000–2800**（范围型）或 **300–700**（单体/远程，打 Boss 更好）区间。

| 调整 | 原因 |
| --- | --- |
| 炸弹 30→12 伤害，冷却 2.5→3 | 1 级伤害是皮鞭 3 倍 |
| 回旋星 14→7，火焰法杖 12→9、燃烧 35%→25% | 同上 |
| 精灵使魔 6→8、冷却 0.9→0.8；雷鸣链 10→12 | 1 级过弱 |
| 雷电指环第一道必劈屏幕内 Boss | 让远程构筑也能打 Boss |

## 5. 经济与养成

### 5.1 局内金币

| 来源 | 数值 |
| --- | --- |
| 金币掉率 | 2% × 1/(1 + 击败/1500)，后期递减，防止金币爆炸 |
| 金币袋 | 0.2%（同样递减），20 金 |
| 精英怪 | 约每 35 秒一只，10 金 + 25% 几率增益道具 |
| 金鼠 | 每 100 秒，抓住 ≈70 金 |
| Boss | 金币袋 30 + 宝箱 20+15×Boss序号 |
| 时间奖励 | 每分钟 20 金，胜利 +500 |
| 每日首局 | 本局全部金币 ×2 |

实测：失败局（6–9 分钟）约 300–600 金，胜利局约 1500–2500 金（含时间与胜利奖励）。

### 5.2 商店价格

```
价格 = 基础价 × (等级+1) × (1 + 0.07 × min(已购总数, 20))
```

前 10 次购买 200–650 金（几乎每局都能买 1–2 个）；后期单项 5000–10000 金（3–5 局一个）。全部强化 + 全部角色 ≈ 11.5 万金，约 55–90 局完成。

## 6. 留存设计（"再来一局"）

| 系统 | 规则 | 心理 |
| --- | --- | --- |
| 不屈意志 | 每连败一局，下一局伤害和生命 +5%（最多 +15%），胜利清零；开局横幅显示 | 失败也在变强，避免连败流失 |
| 每日首局 ×2 金币 | 每天第一局结算金币翻倍 | 每天回来的理由 |
| 差一点提示 | 结算显示"暗夜魔术师只剩 8% 生命""再坚持 1:12 就能见到铁甲将军" | 遗憾感驱动重试 |
| 下一个目标 | 结算显示"可以购买：力量 Lv2"或"还差 120 金币" | 明确的下一步 |
| 成就 | 16 个成就一次性发放金币，首局即可解锁 3–5 个 | 新手早期奖励雨 |
| 命运卡牌 | 开局 1 张 + 每 2 个 Boss 1 张（每局最多 4 张） | 每局都不一样 |
| 红月终局 | 最后两分钟高潮 | 胜利更有成就感，失败也"差一点" |

### 验证方法

```bash
tools/balance-sim/run.sh average 30 6   # 30 名"普通玩家"各玩 6 局
tools/balance-sim/run.sh novice 30 6    # 新手模型
```

输出每局的胜率、中位存活时间、等级、Boss 击败、首次进化时间、各阶段升级间隔、商店等级，以及首胜所需局数。
单批 20–30 名玩家的胜率波动约 ±10%，结论请看多批合并结果。模拟机器人不会像真人一样走位，真实玩家（尤其会躲红圈的）表现通常更好。

## 新武器：棱镜激光 / 荆棘地刺（第 9 轮）

- **棱镜激光**：瞬发直线光束（长 560、半宽 9×范围），贯穿全部敌人；进化「虹光棱镜」（爆裂之心）三道扇形光束
- **荆棘地刺**：在最近的 3 个敌人脚下依次刺出（半径 30×范围）；进化「生命荆棘」（活力獠牙）+4 根，命中 12% 几率回复 1 生命
- 至此 16 个被动道具都是某把武器的进化钥匙，没有"无用道具"
- 同条件对比（Lv8、5:30、40 秒）：激光 9.4k / 虹光 17.9k、地刺 15.0k / 生命荆棘 18.1k，处于现有武器中段（魔杖 10k ~ 雷电指环 19k；进化 11k ~ 30k）
- 武器池从 14 增至 16 后，对照实验（EXCLUDE=laser,spikes）首局胜率无差异

### 发现并修复：新手引导拉低首局胜率

第 7 轮加入的新手引导让首局跳过开局命运卡牌，模拟首局胜率从 ≈22% 掉到 ≈10%。改为第一次升级后补发命运卡牌，恢复到 **22%**（40 名模拟玩家 × 3 局：22% / 40% / 25%）。

## 第 4 张地图：毒雾沼泽（第 12 轮）

- 解锁：熔岩火山胜利后；怪物生命 ×1.7、金币 ×1.9；通关成就「沼泽之王」+2000 金币
- 环境危害「毒泡」：每 ~10 秒 3 个红圈预警（1.1 秒）→ 喷发（小范围伤害）→ 留下 4 秒毒云
  - 玩家在毒云内减速并持续受伤（2 + 时间/150 每跳）
  - 毒云同样伤害怪物（12 + 等级，每 0.5 秒），把怪群引进毒云是核心技巧
- 模拟（30 名新玩家直接进地图 × 4 局）：熔岩 10% / 10% / 3% / 30%，沼泽 7% / 3% / 27% / 27%。毒云的清怪收益抵消了部分生命加成，整体与熔岩相当；实际玩家要先通关熔岩才能进入，带着更高的商店等级
- 注意：模拟脚本的 STAGE 参数需要把目标地图加入已解锁列表，否则会静默回退到月光草原（已修复）

## 性能与性能模式（第 16 轮）

无头模拟测量（不含渲染）：

| 场景 | 怪物 | 活跃精灵 | 文本 | 逻辑耗时 中位 / p95 / 最大 |
| --- | --- | --- | --- | --- |
| 5:00 普通 | ~150 | ~470 | ~25 | 0.03 / 0.09 / 0.3 ms |
| 13:30 红月 + 6 把进化 | 340 | ~1040 | ~51 | 0.17 / 0.35 / 0.95 ms |
| 同上 · 性能模式 | 240 | ~660 | ~31 | 0.11 / 0.28 / 0.78 ms |

- 逻辑开销很小（手机按 10 倍估算也 < 4 ms），瓶颈在渲染：所有精灵来自同一张图集，可合批；伤害数字用 CHAR 缓存共享字图
- **性能模式**（设置中开关；安卓 `benchmarkLevel < 15` 的机型首次启动自动开启）：同屏怪物上限 340 → 240（红月 420 → 290）、只显示暴击伤害数字、粒子数量 1/3
- 难度影响：40 名模拟玩家 × 3 局，性能模式 18% / 28% / 30%，普通模式 22% / 40% / 25%，差异在噪声范围内（怪物少 → 经验也少，互相抵消）

## 新怪物：爆炸蘑菇（第 18 轮）

- 7:00 起混入怪潮（与云朵精同期），生命 28、速度 50
- 倒下后原地红圈预警 0.7 秒再爆炸：玩家受 5 + 时间/90 伤害；周围怪物受 12 + 等级 伤害（半径 60）
- 第一版（5:00 出现、对怪伤害 30 + 等级×2）让游戏变简单：连锁爆炸清怪太快，首局胜率 25–38%、中位等级 75。下调后两次采样首局 22% / 30%、第 3 局 32% / 52%，回到目标区间
- 设计意图：近战型构筑（大蒜、魔法书）要注意别贴着蘑菇；远程构筑可以主动引爆来清怪群

## 噩梦难度（第 19 轮）

- 解锁：首胜后，角色界面模式按钮循环 普通 → 无尽 → 噩梦
- 倍率：普通怪生命 ×1.6、Boss 生命 ×1.5、怪物伤害 ×1.3、金币（拾取与结算奖励）×1.6
- 模拟（30 名玩家 × 8 局，首胜后自动进入噩梦）：首胜多在第 1~3 局；之后第 4~8 局胜率 7% / 23% / 20% / 37% / 23%（平均约 22%），而普通难度此时约 55–60%。给老玩家一个"要认真构筑才能过"的目标，金币加成让失败也有收益

## 手感优化 3（第 24 轮）

- **鞭子特效**：改为月牙形横扫弧光（中间粗、两端尖，白色核心 + 淡蓝灰边 + 内侧两道残影弧），从奶蛙手边 0.08 秒内甩出伸展

## 前期难度 + Boss 生命（第 25 轮，玩家反馈"前期血太厚、Boss 太脆"）
