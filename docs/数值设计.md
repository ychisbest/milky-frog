# 血月割草 · 数值设计

目标：让玩家处在"刚刚好"的紧张区间——每局都差一点、每局都有进步、每天都想再来一局。
所有结论都由 `tools/balance-sim` 的自动化模拟验证（见文末）。

---

## 1. 设计目标（可量化）

| 维度 | 目标 | 实测（30 名模拟玩家 × 6 局） |
| --- | --- | --- |
| 首局胜率 | 25–35%（大部分人差一点） | **≈31%**（普通 20% / 新手 43%） |
| 第 3 局胜率 | ≈50% | **≈50%** |
| 第 5–6 局胜率 | 60–70% | **≈55–60%** |
| 首胜所需局数（中位） | 2–3 局 | **2–3 局** |
| 死亡时间分布 | 峰值在 6–12 分钟（"差一点就到下个 Boss"） | 峰值 6–9 分钟，9–15 分钟占 1/3 |
| 升级节奏 | 0–2 分 8–12 s/级；2–6 分 15–20 s；6–15 分 20–30 s | 8–12 / 10–20 / 13–18 s |
| 首次进化 | 7–10 分钟 | 7.3–10 分钟 |
| 胜利局结束等级 | 60–70（构筑接近完成但不完美） | 60–70 |
| 全部养成完成 | 50–90 局（长线目标） | 约 55–90 局 |

> 难度曲线原则：**前期宽容（学习）→ 中期紧张（筛选）→ 终局高潮（血月 + 死神）**。
> 调参前实测发现曲线是反的（2 分钟史莱姆王最致命、后期几乎无威胁），已修正。

## 2. 成长曲线

### 2.1 升级经验（`Defs.ts · xpForLevel`）

| 等级段 | 每级所需经验 | 设计意图 |
| --- | --- | --- |
| 1–9 | 5 + 5×(lv−1) | 开局 8–12 秒一级，快速成型、立刻爽 |
| 10–29 | 60 + 14×(lv−10) | 中期 15–20 秒一级，每次选择更有分量 |
| 30–49 | 340 + 26×(lv−30) | 后期放缓 |
| 50+ | 860 + 45×(lv−50) | 胜利局约 60–70 级：6 武器满级 + 6 被动满级需 ≈78 次选择，故意差一点 |

### 2.2 升级选项权重（`Battle.ts · buildOptions`）

| 选项 | 权重 |
| --- | --- |
| 已有武器升级 | 3 |
| 已有被动升级 | 2 |
| 凑进化所需的被动（对应武器 ≥5 级） | 5 |
| 新武器（已有 <3 把） | 2.5 |
| 新武器（其余） / 新被动 | 1 |

效果：构筑更容易做深、凑出进化，减少"三个选项都没用"的挫败；随便选的玩家也不会被惩罚（模拟中随机选与精选胜率接近，但精选首次进化早 2–3 分钟）。

## 3. 敌人强度

### 3.1 小怪血量

```
HP = 基础HP × (1 + t/240 + (t/280)²) × 血月(1.3) × 心流系数
```

| 时间 | 0:00 | 5:00 | 10:00 | 15:00 |
| --- | --- | --- | --- | --- |
| 倍率（心流=1） | ×1 | ×3.4 | ×8.1 | ×15.1 |

### 3.2 小怪接触伤害（`dmgRamp`）

```
伤害 = 基础伤害 × (1 + 0.8m + 1.4m²) × 血月(1.25) × (0.8 + 0.2×心流)，m = t/600
```

前期平缓、后期陡峭：5 分钟 ×1.75，10 分钟 ×3.2，15 分钟 ×5.4。Boss 接触伤害不随时间成长。

### 3.3 刷怪节奏要点

- 0–1:30 大量 3 血老鼠和蝙蝠（一击必杀），新手开局就能攒经验；1:15 第一波蝙蝠群是经验盛宴
- 幽灵（快速、抗击退）推迟到 **7:00** 才出现——实测它是 5 分钟"死亡墙"的元凶
- Boss 战期间小怪 −40%，让玩家专心对付 Boss
- **血月（13:00–15:00）**：地面变红、Boss 音乐、刷怪 ×1.8、精英 ×3、血量 ×1.3、伤害 ×1.25，敌人上限 340→420。最后两分钟是高潮，强构筑也要接受考验

### 3.4 Boss 血量

```
Boss HP = 基础HP × (1 + 0.1 × 玩家等级)
```

随玩家等级成长（同吸血鬼幸存者），保证强弱构筑都能打 30–100 秒。前两个 Boss（史莱姆王、骷髅将军）接触伤害降到 5 / 8——实测前期死亡主要来自它们。

### 3.5 心流系统（动态难度，玩家不可见）

| 状态 | 心流变化 | 效果 |
| --- | --- | --- |
| 生命 <35% | −0.03/秒 | 刷怪、血量、伤害放缓，给喘息机会 |
| 生命 >80% 且 6 秒未受伤 | +0.012/秒 | 碾压中，逐渐加压 |
| 生命 >50% | +0.003/秒 | 缓慢加压 |

范围 0.8–1.7。作用于刷怪数量（×心流）、怪物血量（≤1 线性，>1 时 心流^1.5）、接触伤害（0.8+0.2×心流）。
目的：高手不会无聊、新手不会被碾死，所有人都待在紧张区间。

## 4. 武器平衡

基准：同样 40 秒、满屏小怪时的伤害量。1 级时各武器控制在 **2000–2800**（范围型）或 **300–700**（单体/远程，打 Boss 更好）区间。

| 调整 | 原因 |
| --- | --- |
| 炸弹 30→12 伤害，冷却 2.5→3 | 1 级伤害是皮鞭 3 倍 |
| 十字架 14→7，火焰法杖 12→9、燃烧 35%→25% | 同上 |
| 精灵使魔 6→8、冷却 0.9→0.8；雷鸣链 10→12 | 1 级过弱 |
| 雷电指环第一道必劈屏幕内 Boss | 让远程构筑也能打 Boss |

## 5. 经济与养成

### 5.1 局内金币

| 来源 | 数值 |
| --- | --- |
| 金币掉率 | 2% × 1/(1 + 击杀/1500)，后期递减，防止金币爆炸 |
| 金币袋 | 0.2%（同样递减），20 金 |
| 精英怪 | 约每 35 秒一只，10 金 + 25% 几率增益道具 |
| 金鼠 | 每 100 秒，抓住 ≈70 金 |
| Boss | 金币袋 30 + 宝箱 20+15×Boss序号 |
| 时间奖励 | 每分钟 20 金，胜利 +500 |
| 每日首局 | 本局全部金币 ×2 |

实测：失败局（6–9 分钟）约 300–600 金，胜利局约 1500–2500 金（含时间与胜利奖励）。

### 5.2 商店价格

```
价格 = 基础价 × (等级+1) × (1 + 0.07 × min(已购总数, 20))
```

前 10 次购买 200–650 金（几乎每局都能买 1–2 个）；后期单项 5000–10000 金（3–5 局一个）。全部强化 + 全部角色 ≈ 11.5 万金，约 55–90 局完成。

## 6. 留存设计（"再来一局"）

| 系统 | 规则 | 心理 |
| --- | --- | --- |
| 不屈意志 | 每连败一局，下一局伤害和生命 +5%（最多 +15%），胜利清零；开局横幅显示 | 失败也在变强，避免连败流失 |
| 每日首局 ×2 金币 | 每天第一局结算金币翻倍 | 每天回来的理由 |
| 差一点提示 | 结算显示"死神只剩 8% 血量""再坚持 1:12 就能见到骷髅将军" | 遗憾感驱动重试 |
| 下一个目标 | 结算显示"可以购买：力量 Lv2"或"还差 120 金币" | 明确的下一步 |
| 成就 | 16 个成就一次性发放金币，首局即可解锁 3–5 个 | 新手早期奖励雨 |
| 命运卡牌 | 开局 1 张 + 每 2 个 Boss 1 张（每局最多 4 张） | 每局都不一样 |
| 血月终局 | 最后两分钟高潮 | 胜利更有成就感，失败也"差一点" |

### 验证方法

```bash
tools/balance-sim/run.sh average 30 6   # 30 名"普通玩家"各玩 6 局
tools/balance-sim/run.sh novice 30 6    # 新手模型
```

输出每局的胜率、中位存活时间、等级、Boss 击杀、首次进化时间、各阶段升级间隔、商店等级，以及首胜所需局数。
单批 20–30 名玩家的胜率波动约 ±10%，结论请看多批合并结果。模拟机器人不会像真人一样走位，真实玩家（尤其会躲红圈的）表现通常更好。
