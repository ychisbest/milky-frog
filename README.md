# 奶蛙割草 Milky Frog Survivors

幸存者类（Survivors-like）的 32×32 像素风竖屏割草游戏，Cocos Creator 3.8.8，目标平台：微信小游戏。

## 运行

1. 用 Cocos Creator 3.8.8 打开本项目
2. 打开 `assets/scenes/Main.scene`，点击预览（建议在预览设置里选择竖屏机型，如 iPhone 12）
3. 操作：按住屏幕任意位置拖动（摇杆底座固定在按下处）/ WASD / 方向键移动，武器自动攻击；升级时点选卡片或按 1/2/3

## 发布到微信小游戏

1. 菜单 项目 → 构建发布，平台选择 **微信小游戏**
2. 初始场景选 `Main.scene`，**设备方向选 Portrait（竖屏）**，填写 AppID
3. 构建后用微信开发者工具打开 `build/wechatgame`
4. 项目设置中已关闭未使用的引擎模块（Spine、龙骨、TiledMap、物理、视频等）以减小包体

设计分辨率为 720×1280、适配宽度（`settings/v2/packages/project.json`，代码中也会强制设置）。
界面会避开刘海安全区和微信右上角胶囊按钮。

## 广告与上架（个人主体 · 纯广告变现）

启动流程：启动页（健康游戏忠告 + 适龄提示 12+）→ 首次启动弹出用户协议与隐私政策 → 主菜单（右上角 12+ 可查看适龄说明）。

**广告位**（统一在 `assets/scripts/AdConfig.ts` 配置，采用方案一：未配置或广告不可用时，"看广告"按钮自动隐藏）：

| 位置 | 奖励 | 次数 |
| --- | --- | --- |
| 倒下复活 | 满状态原地复活 + 冲击波，8 秒倒计时 | 每局 1 次（无尽模式不提供） |
| 结算 | 本局金币 ×2 | 每局 1 次 |
| 升级 | 免费重抽用完后，看广告重抽 | 每局 2 次 |
| 宝箱 | 再开一次（额外奖励 + 金币） | 每个宝箱 1 次 |
| 开局命运卡牌 | 额外多选一张 | 每局 1 次 |
| 插屏 | 离开结算页时弹出 | 每 3 局 1 次，新用户首日不弹，看过激励视频的那次不弹 |

**开通流量主后的步骤：**
1. 小游戏累计 UV 达到 1000 后，在微信公众平台「流量主」开通，创建 1 个激励视频广告位和 1 个插屏广告位
2. 把广告位 ID 填进 `AdConfig.ts` 的 `rewarded` 和 `interstitial`（可选：在 `rewardedByPlace` 中按位置分别填写，便于分别统计收益）
3. 重新构建上传即可，无需改其他代码

**调试**：`AdConfig.ts` 中 `debugFake: true` 时，浏览器预览会把"看广告"模拟为直接发奖，便于测试流程；**上线前务必改回 `false`**。

**上架注意：**
- 微信后台：小游戏名称填「奶蛙割草」，服务类目选休闲游戏，上传软著，完成小程序备案
- 「设置 → 用户隐私保护指引」需如实填写（本游戏不调用需授权的隐私接口，广告由平台提供）
- 未成年人防沉迷由微信小游戏平台统一处理
- 分享按钮只分享战绩，**不发放任何奖励**（平台禁止诱导分享）
- 广告接口同时兼容抖音小游戏（`tt`），后续移植抖音只需在 `AdConfig.ts` 换成抖音的广告位 ID

## 游戏系统

- **图鉴**（主菜单）：武器 / 进化 / 道具 / 怪物共 67 项，首次获得或击败即收录，未收录显示剪影与获取提示；有新收录时按钮亮红点，结算显示新收录数，收集 50% / 100% 有成就
- **抖音录屏**（`Recorder.ts`，仅抖音环境生效）：开局自动录制，暂停同步暂停，录满 300 秒自动续录；结算页「分享本局录屏」以视频形式分享（不发奖励）
- **性能模式**（设置）：同屏怪物上限 340 → 240、只显示暴击数字、粒子 1/3；安卓 `benchmarkLevel < 15` 的机型首次启动自动开启。性能测量见 `docs/数值设计.md`
- **刷怪节奏**：开局慢、逐步加快，之后每 60 秒一个波峰波谷；波峰轮流出现「怪物包围」「侧翼冲锋」「怪潮来袭」
- **胜利过渡**：胜利后 3 秒庆祝动画（金光、怪物消散成星星、彩带、「胜利!」弹出）再进入结算
- **新手引导**：首局（`Save.tutDone` 为假）跳过开局命运卡牌，底部提示条依次教学：拖动移动（附摇杆演示）→ 自动攻击 → 捡宝石升级 → 三选一 → 生存目标 → Boss 预警；第二局起不再出现
- **主菜单**：开始游戏 / 选择角色 / 永久强化 / 设置，显示金币与最佳记录
- **12 名角色**：各有初始武器与属性加成，后 8 名用金币解锁（含德鲁伊蛙·荆棘地刺、棱镜蛙·棱镜激光）；新春限定「福蛙」击败年兽解锁（永久保留）
- **16 种武器**（最高 8 级）+ **16 种被动道具**，每局最多各 6 个
  - 新武器：火焰法杖（爆炸 + 燃烧地面）、魔法药水（伤害水池）、回旋星（回旋镖）、冰霜新星（冻结）、精灵使魔（跟随宠物射击）、雷鸣链（连锁跳跃闪电）、炸弹（延时大范围爆炸）、棱镜激光（贯穿直线光束）、荆棘地刺（敌人脚下依次刺出）
  - 新被动：幸运草（暴击率）、爆裂之心（暴击伤害）、活力獠牙（击败回复生命）、荆棘甲（受击反伤）
- **武器进化**：武器满级 + 持有对应被动，击败 Boss 后开启宝箱时进化（共 16 种进化，每个被动道具都是一把武器的进化钥匙）

- **命运卡牌**：开局选 1 张，之后每击败 2 个 Boss 再选 1 张（每局最多 4 张），16 种改变规则的祝福：狂战士之心、连锁爆炸、治愈之吻、时间裂隙、宝石风暴、玻璃大炮、贪婪契约、疾风步伐、双生之力、磁暴、连击狂热、星光庇护

- **限时活动**（`Defs.ts` 的 `EVENTS` 按本地日期自动开启；`EVENT.force = 'xmas'` / `true`（新春）强制开启测试）
  - **圣诞**（2026-12-18 ～ 2027-01-03）：限定地图「雪夜小镇」（礼物炸弹），Boss「雪怪王」替换铁甲将军与冰霜巫师（雪球连射 / 冰锥阵 / 冲锋 / 召唤云朵精），击败解锁「圣诞蛙」
  - **新春**（2027-01-28 ～ 02-21）：限定地图「年夜庙会」，Boss「年兽」替换铁甲将军与冰霜巫师（鞭炮环弹幕 / 二连冲撞 / 烟花红圈 / 怒吼召唤）；`EVENT.force = true` 可强制开启测试
- **七日签到**：每天首次回到主菜单自动弹出（新玩家第一局前不弹，每天只自动弹一次），累计签到断签不清零，7 天一轮：100 / 120 / 150 / 180 / 220 / 260 / 600 金币；开通激励视频后可「看视频双倍」；主菜单右上角「签到」按钮未签时亮红点
- **每日任务**：每天按日期抽 3 个不同类型的任务（击败、存活、Boss、进化、金币、宝箱、局数、等级、连击，共 11 种），普通局与挑战局都计入，跨局累计；结算时自动发放金币（100–200/个，全部完成再 +200）。在每日挑战界面查看进度；主菜单「每日挑战」在当日未完成时亮红点
- **每日挑战**：按日期生成（全服同一挑战）：试玩角色（无需解锁）+ 地图 + 特殊规则（怪潮狂奔 / 经验翻倍 / 精英横行 / 金币狂欢 / 无尽怪潮 / 易碎奶蛙）+ 强制命运卡牌，存活 10 分钟得 400 金币（每日一次）

- **永久强化商店**：14 项（力量、护甲、体魄、恢复、冷却、范围、弹速、移速、磁力、成长、幸运、贪婪、重抽、复活），可全额返还
- **金币**：怪物掉落、宝箱、按存活时间结算奖励，胜利额外 +500
- **7 个 Boss**（专属 BGM，HUD 常驻显示下一个 Boss 倒计时，出场前 10 秒警告）：

## 代码结构

| 文件 | 说明 |
| --- | --- |
| `assets/scripts/GameRoot.ts` | 入口组件：状态机、所有界面（含启动页、隐私、复活）、HUD、输入、分享 |
| `assets/scripts/Ads.ts` / `AdConfig.ts` | 广告管理（激励视频 / 插屏，微信与抖音通用）与广告位配置 |
| `assets/scripts/Battle.ts` | 战斗模拟：玩家、怪物、武器、拾取物、刷怪、进化、敌方子弹与危险区域 |
| `assets/scripts/Bosses.ts` | 7 个 Boss 的 AI 与技能 |
| `assets/scripts/Defs.ts` | 全部数值配置（怪物、波次、武器、被动、角色、商店） |
| `assets/scripts/PixelArt.ts` | 程序化像素画（怪物、武器、道具、场景），运行时与角色图一起打包成一张 1024×1024 图集 |
| `assets/scripts/HeroArt.ts` | 8 个（福蛙由猎人蛙叠加红帽生成）奶蛙角色的像素数据（由导入工具自动生成，勿手改） |
| `tools/import-heroes.py` | 角色导入工具：从 3×3 角色参考图（`tools/hero-reference.jpg`）切格、去背景、对齐像素网格、保护眼睛颜色，生成 `HeroArt.ts`。换图后运行 `python3 tools/import-heroes.py <图片>` 即可，角色与格子的对应关系在脚本开头 `HEROES` 中配置 |
| `assets/scripts/Art.ts` | 把图集上传为贴图并生成 SpriteFrame |
| `assets/scripts/Sound.ts` | 背景音乐 / 音效播放（带防叠音节流）、震动 |
| `assets/scripts/Save.ts` | 本地存档 |
| `assets/scripts/UiKit.ts` | 节点 / 按钮 / 面板 / 文本 创建工具（文本默认不用 CHAR 缓存，避免中文撑满共享图集而不显示） |
| `assets/resources/audio/` | 芯片风格音效与 3 首 BGM（MP3，共约 910KB） |
| `tools/balance-sim/` | 数值验证模拟器：`tools/balance-sim/run.sh average 30 6` 模拟 30 名玩家各玩 6 局 |
| `tools/gen-audio.mjs` | 音频合成脚本，修改后执行 `node tools/gen-audio.mjs` 重新生成（需要 lame） |

## 回归测试

```bash
tools/tests/run.sh
```

用模拟引擎跑真实游戏逻辑（无渲染），分三种环境各跑一遍：A 无广告、B 激励视频可用、C 抖音录屏。覆盖新手引导、刷怪节奏、摇杆、胜利 / 倒下动画、复活与广告、每日挑战、限时活动、图鉴、每日任务、签到、毒雾沼泽、噩梦难度、内容合规敏感词等。改动游戏逻辑后先跑一遍。
