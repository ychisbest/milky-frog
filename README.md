# 血月割草 Blood Moon Survivors

类吸血鬼幸存者的 32×32 像素风竖屏割草游戏，Cocos Creator 3.8.8，目标平台：微信小游戏。

## 运行

1. 用 Cocos Creator 3.8.8 打开本项目
2. 打开 `assets/scenes/Main.scene`，点击预览（建议在预览设置里选择竖屏机型，如 iPhone 12）
3. 操作：拖动屏幕任意位置（浮动摇杆）/ WASD / 方向键移动，武器自动攻击；升级时点选卡片或按 1/2/3

## 发布到微信小游戏

1. 菜单 项目 → 构建发布，平台选择 **微信小游戏**
2. 初始场景选 `Main.scene`，**设备方向选 Portrait（竖屏）**，填写 AppID
3. 构建后用微信开发者工具打开 `build/wechatgame`
4. 项目设置中已关闭未使用的引擎模块（Spine、龙骨、TiledMap、物理、视频等）以减小包体

设计分辨率为 720×1280、适配宽度（`settings/v2/packages/project.json`，代码中也会强制设置）。
界面会避开刘海安全区和微信右上角胶囊按钮。

## 广告与上架（个人主体 · 纯广告变现）

启动流程：启动页（健康游戏忠告 + 适龄提示 12+）→ 首次启动弹出用户协议与隐私政策 → 主菜单（右上角 12+ 可查看适龄说明）。

**广告位**（统一在 `assets/scripts/AdConfig.ts` 配置，采用方案一：未配置或广告不可用时，"看广告"按钮自动隐藏）：

| 位置 | 奖励 | 次数 |
| --- | --- | --- |
| 死亡复活 | 满血原地复活 + 冲击波，8 秒倒计时 | 每局 1 次（无尽模式不提供） |
| 结算 | 本局金币 ×2 | 每局 1 次 |
| 升级 | 免费重抽用完后，看广告重抽 | 每局 2 次 |
| 宝箱 | 再开一次（额外奖励 + 金币） | 每个宝箱 1 次 |
| 开局命运卡牌 | 额外多选一张 | 每局 1 次 |
| 插屏 | 离开结算页时弹出 | 每 3 局 1 次，新用户首日不弹，看过激励视频的那次不弹 |

**开通流量主后的步骤：**
1. 小游戏累计 UV 达到 1000 后，在微信公众平台「流量主」开通，创建 1 个激励视频广告位和 1 个插屏广告位
2. 把广告位 ID 填进 `AdConfig.ts` 的 `rewarded` 和 `interstitial`（可选：在 `rewardedByPlace` 中按位置分别填写，便于分别统计收益）
3. 重新构建上传即可，无需改其他代码

**调试**：`AdConfig.ts` 中 `debugFake: true` 时，浏览器预览会把"看广告"模拟为直接发奖，便于测试流程；**上线前务必改回 `false`**。

**上架注意：**
- 微信后台：小游戏名称填「血月割草」，服务类目选休闲游戏，上传软著，完成小程序备案
- 「设置 → 用户隐私保护指引」需如实填写（本游戏不调用需授权的隐私接口，广告由平台提供）
- 未成年人防沉迷由微信小游戏平台统一处理
- 分享按钮只分享战绩，**不发放任何奖励**（平台禁止诱导分享）
- 广告接口同时兼容抖音小游戏（`tt`），后续移植抖音只需在 `AdConfig.ts` 换成抖音的广告位 ID

## 游戏系统

- **主菜单**：开始游戏 / 选择角色 / 永久强化 / 设置，显示金币与最佳记录
- **8 名角色**：各有初始武器与属性加成，后 6 名用金币解锁
- **14 种武器**（最高 8 级）+ **16 种被动道具**，每局最多各 6 个
  - 新武器：火焰法杖（爆炸 + 燃烧地面）、圣水（伤害水池）、十字架（回旋镖）、冰霜新星（冻结）、精灵使魔（跟随宠物射击）、雷鸣链（连锁跳跃闪电）、炸弹（延时大范围爆炸）
  - 新被动：幸运草（暴击率）、爆裂之心（暴击伤害）、吸血獠牙（击杀回血）、荆棘甲（受击反伤）
- **武器进化**：武器满级 + 持有对应被动，击败 Boss 后开启宝箱时进化（共 7 种进化）

  | 武器 | 需要被动 | 进化 |
  | --- | --- | --- |
  | 皮鞭 | 空心之心 | 血之泪 |
  | 魔杖 | 空白之书 | 圣杖 |
  | 飞刀 | 护腕 | 千刃 |
  | 飞斧 | 烛台 | 死亡螺旋 |
  | 圣经 | 咒语绑定 | 不朽圣典 |
  | 大蒜 | 番茄 | 灵魂吞噬者 |
  | 雷电指环 | 复制器 | 雷霆之环 |
  | 火焰法杖 | 菠菜 | 地狱火 |
  | 圣水 | 吸引宝珠 | 圣泉（池中回血） |
  | 十字架 | 幸运草 | 审判十字（必定暴击） |
  | 冰霜新星 | 盔甲 | 永冻领域（冻结敌人受伤 +50%） |
  | 精灵使魔 | 皇冠 | 精灵王 |
  | 雷鸣链 | 翅膀 | 天罚雷链（跳跃处爆炸） |
  | 炸弹 | 荆棘甲 | 连环爆破（分裂子炸弹） |

- **命运卡牌**：开局选 1 张，之后每击败 2 个 Boss 再选 1 张（每局最多 4 张），12 种改变规则的祝福：狂战士之魂、连锁爆炸、吸血之吻、时间裂隙、宝石风暴、玻璃大炮、贪婪契约、幽灵步伐、双生之力、磁暴、杀戮狂热、圣光庇护
- **地图事件**：可破坏的火盆掉落道具；精英怪（金色、约每 35 秒一只）掉落金币和增益；金鼠（约每 100 秒）逃跑 14 秒，抓住就下金币雨
- **增益道具**：时停怀表（冻结全场）、圣十字（清屏）、狂暴药水（伤害 +50% 移速 +30%）、圣盾（抵挡 3 次伤害）
- **无尽模式**：首胜后在角色界面切换；15 分钟后 Boss 循环出现、一轮比一轮强
- **成就**：16 个成就，结算时发放金币奖励
- **永久强化商店**：14 项（力量、护甲、体魄、恢复、冷却、范围、弹速、移速、磁力、成长、幸运、贪婪、重抽、复活），可全额返还
- **金币**：怪物掉落、宝箱、按存活时间结算奖励，胜利额外 +500
- **6 个 Boss**（专属 BGM，HUD 常驻显示下一个 Boss 倒计时，出场前 10 秒警告）：

  | 时间 | Boss | 技能 |
  | --- | --- | --- |
  | 2:00 | 史莱姆王 | 跳跃砸地（落点预警）、召唤史莱姆、半血分裂 |
  | 4:30 | 骷髅将军 | 骨刺弹环、预警直线冲锋、召唤骷髅 |
  | 7:00 | 吸血鬼伯爵 | 血弹扇射、瞬移 + 血环、蝙蝠风暴 |
  | 9:30 | 冰霜巫妖 | 冰霜螺旋弹幕、冰锥阵（圆形预警）、减速冰域 |
  | 12:00 | 深渊魔眼 | 预警死亡射线（扫射）、追踪眼球、双层弹环 |
  | 14:00 | 死神（最终） | 回旋镰刀、连续冲刺、亡魂召唤、暗影弹环；击败即提前胜利 |

  Boss 血量随玩家等级成长，35% 血量以下狂暴（技能更快更多）；下一个 Boss 到来时未击败的 Boss 会撤退（无奖励）；Boss 战期间小怪减少 40%。击败掉落宝箱、金币袋和烤鸡
- **蝙蝠群**：1:15、3:20、6:00、8:20、10:50
- **结算**：存活时间、等级、击杀、最高连杀、金币、新成就、各武器伤害统计
- **设置**：音乐 / 音效 / 震动开关，统计数据；存档保存在本地（`sys.localStorage`）
- **打击感**：受击白闪 + 挤压、10% 暴击（大号橙色数字）、死亡像素碎片、宝石弹出、多杀顿帧与震屏、连杀计数与里程碑、升级冲击波击退
- **前期节奏**：开局大量一击必杀的老鼠和蝙蝠，75 秒第一波蝙蝠群，快速攒经验；离屏太远的宝石会合并成红宝石出现在玩家附近
- **数值与留存**（详见 [docs/数值设计.md](docs/数值设计.md)）：四段式升级曲线、带权重的升级选项、隐藏的心流动态难度、13:00 起「血月」终局冲刺、连败加成「不屈意志」、每日首局双倍金币、结算"差一点"提示与下一个强化目标
- 切到后台自动暂停，支持微信分享

## 代码结构

| 文件 | 说明 |
| --- | --- |
| `assets/scripts/GameRoot.ts` | 入口组件：状态机、所有界面（含启动页、隐私、复活）、HUD、输入、分享 |
| `assets/scripts/Ads.ts` / `AdConfig.ts` | 广告管理（激励视频 / 插屏，微信与抖音通用）与广告位配置 |
| `assets/scripts/Battle.ts` | 战斗模拟：玩家、怪物、武器、拾取物、刷怪、进化、敌方子弹与危险区域 |
| `assets/scripts/Bosses.ts` | 6 个 Boss 的 AI 与技能 |
| `assets/scripts/Defs.ts` | 全部数值配置（怪物、波次、武器、被动、角色、商店） |
| `assets/scripts/PixelArt.ts` | 程序化像素画，运行时打包成一张 512×512 图集 |
| `assets/scripts/Art.ts` | 把图集上传为贴图并生成 SpriteFrame |
| `assets/scripts/Sound.ts` | 背景音乐 / 音效播放（带防叠音节流）、震动 |
| `assets/scripts/Save.ts` | 本地存档 |
| `assets/scripts/UiKit.ts` | 节点 / 按钮 / 面板 / 文本 创建工具（文本默认不用 CHAR 缓存，避免中文撑满共享图集而不显示） |
| `assets/resources/audio/` | 芯片风格音效与 3 首 BGM（MP3，共约 910KB） |
| `tools/balance-sim/` | 数值验证模拟器：`tools/balance-sim/run.sh average 30 6` 模拟 30 名玩家各玩 6 局 |
| `tools/gen-audio.mjs` | 音频合成脚本，修改后执行 `node tools/gen-audio.mjs` 重新生成（需要 lame） |
