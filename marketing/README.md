# 《奶蛙割草》上架与推广素材总目录

所有图片和视频都由真实游戏逻辑录制生成（`tools/promo/` 流水线）。游戏内容更新后按「重新生成」一节重跑即可，素材会自动同步最新的角色、武器、地图和数值。

**从哪里开始**：先看 `文案/14_提审与上线清单.md`，它按时间顺序列出每一步要用的素材。

## 五、重新生成

```bash
# 1. 采集游戏画面（截图 / 视频帧），所有图片和视频的基础
tools/promo/run.sh shots                 # 商店截图用的游戏画面
tools/promo/run.sh video                 # 宣传片 / 短视频用的游戏画面
tools/promo/run.sh compare               # 进化对比分屏
tools/promo/run.sh tutorial              # 新手教程
tools/promo/run.sh newweap               # 新武器
tools/promo/run.sh newmap                # 新地图
tools/promo/run.sh xmasvid               # 圣诞活动

# 2. 合成素材
python3 tools/promo/make_assets.py       # 商店截图、图标、主视觉、分享卡片
python3 tools/promo/make_video.py        # 宣传片 + 短视频 + GIF
python3 tools/promo/make_landscape.py    # 横版宣传片
python3 tools/promo/make_tutorial.py     # 新手教程视频
python3 tools/promo/make_compare.py      # 进化对比视频
python3 tools/promo/make_showcase.py     # 角色展示视频
python3 tools/promo/make_newweap.py      # 新武器短视频
python3 tools/promo/make_newmap.py       # 新地图短视频
python3 tools/promo/make_xmasvid.py      # 圣诞短视频
python3 tools/promo/make_guides.py       # 图鉴攻略海报（数据直接读取 Defs.ts）
python3 tools/promo/make_ads.py          # 买量广告图
python3 tools/promo/make_bilibili.py     # B 站封面
python3 tools/promo/make_cny.py          # 新春活动素材
python3 tools/promo/make_xmas.py         # 圣诞活动素材
python3 tools/promo/make_softcopyright.py  # 软著材料 PDF
```

> 商店截图按 `make_assets.py` 中 `CAPTIONS` 的顺序编号；插入新截图后编号会顺延，引用截图的文案需要同步修改。
