# 《奶蛙割草》用户协议与隐私政策

> 游戏内全文来自 `assets/scripts/Legal.ts`。首次启动弹窗和「设置」里的《用户协议》《隐私政策》按钮会打开它。
> 微信小游戏打不开网页。不要把协议做成外链、公众号文章或跳转到其他小游戏，审核会按「点击无反应 / 打开无关页面 / 报错 / 跳转其他小游戏」驳回。
> 当前配置：云存档关闭（`SocialConfig.cloudEnv` 为空），好友排行开启。改配置后以游戏内生成的文字为准。
> 生效日期：2026年10月26日。运营者：个人开发者。联系方式：小游戏右上角「…」→「反馈与投诉」。
> 改协议正文时把 `Legal.ts` 的 `PRIVACY_VER` 加 1。已经同意过的玩家会再看一次弹窗。

## 后台「用户隐私保护指引」

| 后台选项 | 填写 |
| --- | --- |
| 开发者处理的信息 | 不勾选姓名、手机号、位置、相册、麦克风、通讯录、昵称头像 |
| 好友关系 | 勾选。用途：展示好友排行榜（开放数据域，主程序读不到好友昵称头像） |
| 第三方 | 微信广告、微信统计。本游戏拿不到广告侧个人信息 |
| 用户权益 | 删除小游戏即可清除手机里的本地数据 |
| 联系方式 | 与游戏内一致，不要填打不开的网址 |

游戏内协议条目与 `Legal.ts` 保持一致：不收集姓名和手机号；进度存在本地；匿名统计游戏行为；好友排行只提交成绩；广告由微信提供；联系走「反馈与投诉」。
