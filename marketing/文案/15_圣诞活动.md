# 圣诞活动「雪怪王来了」运营方案

> 活动时间：2026-12-18 ～ 2027-01-03（游戏内按本地日期自动开启，见 `Defs.ts` 的 `EVENTS`；测试时设 `EVENT.force = 'xmas'`）
> 与上线节奏的关系：12 月上旬上线 → 一周后圣诞活动，正好给冷启动期一个"内容更新"话题。

## 一、活动内容（已实现）

| 内容 | 说明 |
| --- | --- |
| 限定地图「雪夜小镇」 | 雪地、圣诞树、礼物盒、拐杖糖、雪人；环境危害「礼物炸弹」从天而降（红圈预警） |
| 限定 Boss「雪怪王」 | 替换铁甲将军（4:30）与冰霜巫师（9:30）：雪球连射、冰锥阵、冲锋撞击、召唤云朵精 |
| 限定角色「圣诞蛙」 | 击败雪怪王解锁，**活动结束后永久保留**；初始武器冰霜新星，金币 +20%、冷却 -8% |
| 主菜单 | 活动期间显示「圣诞活动进行中」提示 |
| 成就 / 图鉴 | 「雪夜英雄」+600 金币；雪怪王收录进怪物图鉴 |
| 每日挑战 | 不使用活动内容 |

## 三、节奏

| 时间 | 动作 |
| --- | --- |
| 12/11 | 发预告海报「雪地里有个大脚印……」 |
| 12/14 | 提审圣诞版本（如首发版已包含活动代码，则无需再提审，按日期自动开启） |
| 12/18 | 活动开启：换图标角标、发主视觉推文 |
| 12/18–12/24 | 短视频「雪怪王打法」「圣诞蛙解锁」日更 |
| 12/24–12/25 | 平安夜 / 圣诞推文：「和奶蛙一起过圣诞」 |
| 01/03 | 活动结束，换回常规图标；预告 1/28 新春活动 |

> 💡 建议：首发版本就带上圣诞和新春两个活动的代码（按日期自动开关），避免节日前审核排队。

## 四、文案

- 推文标题：**圣诞快乐！雪怪王闯进了奶蛙的小镇🎄**
- 正文：雪夜小镇出现了巨大的脚印……戴着圣诞帽的雪怪王会扔雪球、召唤云朵精。打败它，就能把戴圣诞帽的「圣诞蛙」带回家（活动结束后永久保留）！微信搜索「奶蛙割草」。
- 小红书：**圣诞摸鱼｜给奶蛙戴上了圣诞帽🎅🐸**　#圣诞节 #小游戏推荐 #奶蛙割草 #像素游戏
- 短视频开头 3 秒：雪怪王剪影 → 圣诞帽掉下来 → "雪怪王来了！"

## 五、合规

- 圣诞蛙只能通过**击败雪怪王**获得，与分享、邀请、广告无关
- 不使用真实品牌圣诞形象（可口可乐圣诞老人等）
