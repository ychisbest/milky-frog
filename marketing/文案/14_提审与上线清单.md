## G. 常见驳回原因与对策

| 驳回原因 | 对策 |
| --- | --- |
| 诱导分享 | 分享无任何奖励；文案不写"分享领奖" |
| 隐私指引未填写 / 不一致 | 后台指引与游戏内弹窗一致（均为"不收集个人信息"） |
| 类目不符 | 选择休闲游戏，描述中不出现"抽奖""博彩"类字眼 |
| 广告遮挡 / 误触 | 插屏只在结算后、每 3 局一次、新用户首日不弹 |
| 内容涉及他人 IP | 宣传与游戏内只使用原创奶蛙形象，不提及其他 IP 名称 |
