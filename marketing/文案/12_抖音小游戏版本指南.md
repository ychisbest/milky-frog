# 抖音小游戏版本：上架与推广指南

> 时间点：微信版稳定后（计划 2027 年 1 月），见 `04_上线推广计划.md`。
> 代码层面：广告模块 `Ads.ts` 已同时兼容 `wx` / `tt` 接口，构建时选择「抖音小游戏」平台即可；分享、胶囊按钮位置等差异见下文。

## 一、与微信版的差异清单

| 项目 | 微信 | 抖音 | 本游戏的处理 |
| --- | --- | --- | --- |
| 构建平台 | 微信小游戏 | 抖音小游戏（Cocos 构建面板选择） | 同一份代码 |
| 广告 | 流量主（激励视频 / 插屏） | 穿山甲 / 抖音广告（激励视频 / 插屏） | `AdConfig.ts` 分别填写两个平台的广告位 ID |
| 开通门槛 | 累计 UV ≥ 1000 | 以后台为准（通常需完成实名与基础数据） | 无广告位时自动隐藏广告按钮（方案一） |
| 右上角按钮 | 胶囊菜单 | 胶囊菜单（尺寸略不同） | `computeSafe()` 已读取实际胶囊位置 |
| 分享 | 好友 / 朋友圈 | 好友 / 抖音视频 | 同样**不发放分享奖励** |
| 录屏分享 | 无 | **游戏录屏（GameRecorderManager）** | **已接入**（`Recorder.ts`）：开局自动录制，结算页「分享本局录屏」 |
| 软著 / 备案 | 需要 | 需要（同一套材料） | `软著材料/` 直接复用 |
| 适龄提示 / 防沉迷 | 需要 | 需要 | 启动页已有 12+ 与健康游戏忠告 |

## 三、抖音专属玩法：录屏 + 挂载

1. **游戏内录屏（已实现）**：开局自动录制（抖音单段上限 300 秒，录满自动续录，结算时取最近一段，最后一段不足 15 秒则用上一段），暂停时同步暂停；结算页出现「分享本局录屏」，自动带标题与话题 #奶蛙割草 #小游戏。分享不给任何奖励。
2. **短视频挂载小游戏**：每条视频左下角挂「奶蛙割草」小游戏锚点，点击直接进入，转化率远高于"搜索"引导。
3. **达人任务**：在「抖音小游戏 · 达人推广任务」后台发布任务，按播放量 / 进入人数结算，素材包直接用 `marketing/`。

## 五、注意事项

- 抖音审核对"诱导下载 / 诱导分享 / 虚假宣传"同样严格：视频里不要出现"分享领奖励""不玩后悔"等字眼
- 抖音文案中不要出现"微信搜索"，统一改为"抖音搜索「奶蛙割草」"或直接挂载
- 两个平台的存档互不相通（本地存档），FAQ 中说明
