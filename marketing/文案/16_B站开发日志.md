## EP1 · 所有怪物都是用代码画出来的

**标题**：我没有美术，所以用代码画出了游戏里所有的怪物
**时长**：约 4 分钟

| 段落 | 画面 | 口播要点 |
| --- | --- | --- |
| 0:00 开场 | 满屏割草实机（`视频/短视频_满屏割草_14s.mp4`） | 这些怪物没有一张是画图软件画的 |
| 0:20 问题 | 空白画布 | 独立开发最大的坑：美术。我选择用代码"画" |
| 0:50 原理 | 代码片段 `c.ellipse(...)` + 逐步出现的史莱姆王 | 椭圆、矩形、线条 + 描边 = 像素画；两帧动画就是两次绘制 |
| 1:50 图集 | 1024×1024 图集（运行时生成） | 全部怪物、武器、地图打包成一张图，手机上渲染更省 |
| 2:40 主角 | 参考图 → 导入工具 → 奶蛙 | 主角是从像素参考图导入的：自动去背景、对齐网格、保护眼睛颜色 |
| 3:30 结尾 | Boss 图鉴海报 `图鉴攻略/04_Boss图鉴.png` | 9 个 Boss 全部这样画出来；下期讲数值 |

## EP2 · 我让 40 个机器人帮我调数值

**标题**：首局胜率 22%，是我让 40 个机器人玩了上千局调出来的
**时长**：约 5 分钟

| 段落 | 画面 | 口播要点 |
| --- | --- | --- |
| 0:00 开场 | 结算界面"差一点"提示 | 好玩的难度是"差一点就赢" |
| 0:30 机器人玩家 | 终端里滚动的模拟输出表 | 不渲染画面，只跑游戏逻辑，1 秒跑完一局 |
| 1:30 第一次结果 | 胜率 80% 的表格 | 太简单、金币爆炸、精英怪刷屏 |
| 2:30 调整 | 难度曲线图（`docs/数值设计.md`） | 前期多给一刀一只的小怪，后期指数上升，13:00 红月冲刺 |
| 3:30 意外 | 新手引导让胜率掉到 10% | 新手首局少了一张命运卡 → 改成第一次升级后补发 |
| 4:30 结尾 | 第 1/2/3 局胜率柱状图（封面同款） | 22% → 40% → 50%：每输一次，都更强一点 |

## EP3 · 一个 Boss 是怎么设计出来的

**标题**：割草游戏的 Boss 怎么做才不"恶心"？我的三条规则
**时长**：约 4 分钟

| 段落 | 画面 | 口播要点 |
| --- | --- | --- |
| 0:00 开场 | 水晶魔眼激光扫射 | 被秒杀不好玩，被"看见了却没躲开"才好玩 |
| 0:30 规则 1 预警 | 红圈、红线特写 | 所有技能都先给红色预警；冰雪地图上蓝色看不清，所以统一用红色 |
| 1:30 规则 2 节奏 | 技能循环示意：喷吐 → 舌击 → 跳砸 → 召唤 | 每个 Boss 4 个技能轮换，低生命时狂暴加快 |
| 2:30 规则 3 地图配合 | 毒沼巨蟾 + 毒云；年兽 + 烟花 | Boss 和地图机制呼应 |
| 3:30 结尾 | Boss 倒计时 HUD | 屏幕上方永远告诉你下一个 Boss 还有多久 |

## EP4 · 一个人做小游戏：从空项目到上线

**标题**：一个人做微信小游戏，从空项目到上线我都做了什么
**时长**：约 5 分钟

| 段落 | 画面 | 口播要点 |
| --- | --- | --- |
| 0:00 开场 | 主视觉 | 这是我一个人做的游戏 |
| 0:20 时间线 | 文字时间线 | 玩法 → 音乐音效 → 竖屏适配 → 数值 → Boss → 活动 → 上架素材 |
